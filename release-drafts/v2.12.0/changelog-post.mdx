## v2.12.0 is live

Firecrawl v2.12.0 introduces Alexandria provider tools, team-owned MCP connectors, natural-language tool discovery, and `GET /v2/exchange/recommendations`; an enterprise Safe Mode; HLS session replay and zero-data-retention runs across `/interact`, `/browser`, and `/agent` with per-team ZDR retention tiers for agent runs; full agent list/effort/terms/country/traces controls across every SDK; developer search in every first-party SDK; a `GET /v2/parse/formats` endpoint; a free `gov` search category with filters; country selection for browser and interact sessions; the new `menu` scrape format; image OCR by default — plus a long list of security and reliability fixes.

### Highlights

- **Alexandria provider tools, connectors, and natural-language discovery** — Discover and execute third-party provider tools through Firecrawl. Search with any natural-language query (no `sources: ["alexandria"]` or team flag needed) to get back tool contracts; scrape with `domainTools: true` to attach tools matched to a page's domain; or scrape with an `alexandria` body to execute one to ten provider calls with idempotent replays. Alexandria calls now accept `zeroDataRetention: true` end-to-end, and teams with the `exchangeRetrieve` flag can connect their own remote MCP server as a private Alexandria provider through `/v2/exchange/connectors*`. Available in the JavaScript, Python, Go, and Rust SDKs.
- **Safe Mode** — New enterprise Safe Mode enforced across `/scrape`, `/crawl`, `/batch/scrape`, `/search`, `/map`, `/extract`, `/interact`, and `/monitor`. Restricted sites terminate the scrape, blocked options return `403 SAFE_MODE_BLOCKED`, and Lockdown runs cache-only with zero data retention.
- **`menu` scrape format** — Added a deterministic structured `menu` format that returns restaurant menu data in `document.menu`, available in all 9 SDKs and gated behind the `menuBeta` team flag.
- **Session Replay and ZDR for `/interact` and `/agent`** — `GET /v2/interact/:sessionId/replay` and `/replay/:pageId` return HLS playlists of recorded browser tabs with pre-signed segments (opt in with `recordSession: true`). Sessions, `/v2/browser`, and `/v2/agent` all now accept `zeroDataRetention: true`, with recording and saved profiles rejected, child calls inheriting the flag, request content dropped from logs, and (for `/v2/agent`) Exchange still available on ZDR-safe provider capabilities.
- **Agent list, effort, country, terms, traces, and full-SDK parity** — `GET /v2/agent` with cursor pagination and per-run threading metadata, `effort: "low" | "medium" | "high"` running against `spark-2`, `location: { country }` for a run-wide proxy country, `exchange.onTermsRequired: "skip" | "ask"`, `partial` / `partialSchemaValid` / `stopReason` on failed runs, plus `GET /v2/agent/:id/trace` and `/snapshots/:snapshotId`. The JavaScript, Python, Go, Rust, Java, .NET, PHP, Ruby, and Elixir SDKs all accept `exchange`, `threadId`, `mode`, and `location.country` on `POST /v2/agent`, and the .NET SDK now ships the full agent and Interact surface.
- **`GET /v2/parse/formats`** — Added a read-only endpoint that lists every upload type `/v2/parse` accepts (format id, kind, extensions, MIME types, and per-deployment availability). Clients no longer need to mirror `document-formats.ts` / `image-formats.ts`. Shipped in all nine SDKs.
- **`gov` search category with filters** — Added a free `gov` category on `POST /v2/search` and a dedicated `POST /v2/search/gov` endpoint that returns government-source web results, now with optional `jurisdiction`, `court`, `courtType`, `cites`, and `domain` filters on JavaScript, Python, and Elixir. Shares a per-team daily budget with the Research Index, sized by plan (1,000/day on Free–Standard and keyless, 2,000 on Growth, unlimited on Scale and Enterprise).
- **Developer search in every SDK** — Added `developerSearch` / `developer_search` methods (and the Elixir equivalent) on `POST /v2/search/developer` to the Go, Rust, Java, PHP, Ruby, .NET, and Elixir SDKs, bringing every first-party SDK to parity with the existing JavaScript and Python surface.
- **`X-Integration` header and credit-usage breakdown** — Clients that cannot modify request bodies can now attribute usage with an `X-Integration` header on every job-creating route, and `GET /v2/team/credit-usage/historical` accepts `byEndpoint=true` and `bin=day` for a per-endpoint, per-day split of historical usage.
- **Keyless World ID buckets** — Keyless users can now verify a World ID through `POST /v2/keyless/world-id/device` + `/token` to pin into a per-human daily bucket with 20% more requests and credits than the per-IP tier.
- **Country for browser and interact sessions** — `POST /v2/browser` now accepts `location.country`, and interact sessions created from a scrape inherit `location.country`, so sessions come up from the geography the scrape asked for instead of always running from the US.
- **Auto-resume for large-document scrapes** — The JavaScript and Python SDKs now transparently resume `/scrape` when the API signals `processing_continues`, so oversized PDF scrapes turn into one slow successful call instead of a retry loop.
- **Threat Protection, IP Restriction, and API key scope lockdown** — Three new enterprise controls: URL-level threat classification through Google Web Risk or Zscaler ZIA (billed `+2` credits per scanned URL), per-team API key IP allowlists (IPv4, IPv6, CIDR), and per-key allowlists for output formats and endpoint groups enforced server-side.
- **SIEM Logging** — Added org-scoped SIEM Logging that delivers scrape activity events to third-party destinations through a shared, replica-safe queue with retries.
- **PDF page attribution** — Added `parsers[].pageMarkers` for inline page markers in `document.markdown`, `parsers[].pages` for per-page markdown, and `parsers[].blocks` for typed PDF layout blocks.
- **Image OCR by default** — Raster PNG, JPEG, WebP, AVIF, and JPEG 2000 inputs now route through the image parser and return a one-page OCR document.
- **Prompt-injection guard for JSON extraction** — `checkPromptInjection` is now a top-level scrape option across every endpoint that scrapes (and across every SDK), running a classifier on the page once per scrape and failing fast with `SCRAPE_PROMPT_INJECTION_DETECTED` on detection.
- **Abortable crawls in JS and Python** — `crawl()` now stops polling and cancels its server-side job when the caller aborts (JS `AbortSignal`, Python `asyncio` cancellation), so a timed-out caller no longer leaves a crawl burning credits.
- **`GET /v2/exchange/recommendations`** — New endpoint that returns Exchange providers suggested from the caller's own last-30-day Firecrawl usage, so the dashboard, MCP apps, and ChatGPT sidebar can share one Recommended shelf without each one reading usage data itself.
- **Per-team agent ZDR retention tier** — The new `agentZdrRetentionMinutes` team flag lets an org cut the ZDR agent result window below the default 24 hours, with tiers of 15, 30, 60, 360, and 1440 minutes; `expiresAt` on `GET /v2/agent/:id` now reflects the configured retention.
- **Per-org FirePDF training opt-out** — Added a `trainingRestricted` team flag so an organization can be excluded from FirePDF's model-training capture independently of its ZDR configuration.
