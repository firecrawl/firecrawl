## v2.12.0 is live

Firecrawl v2.12.0 ships Alexandria provider tools and connectors with natural-language discovery, a new `skills` search source, and `GET /v2/exchange/recommendations`; enterprise Safe Mode, Threat Protection, IP and API-key scope lockdown, and SIEM Logging; a `usOnly` team flag that pins every model, search, Exchange, agent, and PDF/OCR call to US capacity; HLS session replay and zero-data-retention runs across `/interact`, `/browser`, and `/agent` with per-team ZDR retention tiers; full agent list/effort/safe/terms/country/traces controls across every SDK; developer search in every first-party SDK; a `GET /v2/parse/formats` endpoint; a free `gov` search category with filters and a 300/min cap; country selection for browser and interact sessions; the new `menu` scrape format; image OCR by default; dual-auth OIDC for Vercel Marketplace integrations; MCP credits spent first on hosted MCP calls; TLS certificates verified by default — plus a long list of security and reliability fixes.

### Highlights

- **Alexandria provider tools, connectors, and natural-language discovery** — Discover and execute third-party provider tools through Firecrawl. Search with any natural-language query (no `sources: ["alexandria"]` or team flag needed) to get back tool contracts; scrape with `domainTools: true` to attach tools matched to a page's domain; or scrape with an `alexandria` body to execute one to ten provider calls with idempotent replays. Alexandria calls now accept `zeroDataRetention: true` end-to-end, and teams with the `exchangeRetrieve` flag can connect their own remote MCP server as a private Alexandria provider through `/v2/exchange/connectors*`. Available in the JavaScript, Python, Go, and Rust SDKs.
- **US-only processing** — New `usOnly` team flag routes every model call (OpenAI through the US-only project key, Anthropic with `inference_geo: "us"`, Vertex through the US multi-region endpoint), web/search/map/research/gov/Exchange calls, `/v2/agent` runs, and PDF parsing / image OCR / PII redaction to US capacity; features without a US route fail with `403 US_ONLY_UNAVAILABLE` instead of degrading quietly.
- **Safe Mode, Threat Protection, IP Restriction, API key scope lockdown, and SIEM Logging** — A pack of enterprise controls: org-level Safe Mode across every scrape-adjacent endpoint, URL-level threat classification through Google Web Risk or Zscaler ZIA (billed `+2` credits per scanned URL), per-team API key IP allowlists (IPv4, IPv6, CIDR), per-key allowlists for output formats and endpoint groups enforced server-side, and org-scoped SIEM Logging that delivers scrape activity events to third-party destinations through a replica-safe queue with retries.
- **Session Replay and ZDR for `/interact`, `/browser`, and `/agent`** — `GET /v2/interact/:sessionId/replay` and `/replay/:pageId` return HLS playlists of recorded browser tabs with pre-signed segments (opt in with `recordSession: true`). Sessions, `/v2/browser`, and `/v2/agent` all now accept `zeroDataRetention: true`, with recording and saved profiles rejected, child calls inheriting the flag, request content dropped from logs, ZDR sessions restricted to Firecrawl's ZDR proxy exits, and (for `/v2/agent`) Exchange still available on ZDR-safe provider capabilities.
- **Agent list, effort, country, terms, safe search, traces, and full-SDK parity** — `GET /v2/agent` with cursor pagination and per-run threading metadata, `effort: "low" | "medium" | "high"` running against `spark-2`, `location: { country }` for a run-wide proxy country, `exchange.onTermsRequired: "skip" | "ask"`, a new `safe` option that filters explicit content from every search the agent makes (sub-agents included), `partial` / `partialSchemaValid` / `stopReason` on failed runs, plus `GET /v2/agent/:id/trace` and `/snapshots/:snapshotId`. The JavaScript, Python, Go, Rust, Java, .NET, PHP, Ruby, and Elixir SDKs all accept `exchange`, `threadId`, `mode`, and `location.country` on `POST /v2/agent`, and the .NET SDK now ships the full agent and Interact surface.
- **`gov` search category with filters, higher limits, and a new `skills` source** — Added a free `gov` category on `POST /v2/search` and a dedicated `POST /v2/search/gov` endpoint with optional `jurisdiction`, `court`, `courtType`, `cites`, and `domain` filters, now capped at 300 requests/minute. `POST /v2/search` also picks up a new `skills` source that returns provider-authored skill cards alongside web and Alexandria results, free and not counted in `creditsUsed`. Gov and research indexes share a per-plan daily budget (1,000/day on Free–Standard and keyless, 2,000 on Growth, unlimited on Scale and Enterprise).
- **`GET /v2/parse/formats` and the `menu` scrape format** — New read-only endpoint lists every upload type `/v2/parse` accepts (format id, kind, extensions, MIME types, and per-deployment availability) across all nine SDKs, and a new deterministic `menu` scrape format returns restaurant menu data in `document.menu` behind the `menuBeta` team flag.
- **Developer search in every SDK** — Added `developerSearch` / `developer_search` methods (and the Elixir equivalent) on `POST /v2/search/developer` to the Go, Rust, Java, PHP, Ruby, .NET, and Elixir SDKs, bringing every first-party SDK to parity with the existing JavaScript and Python surface.
- **MCP credits and raised rate limits for hosted MCP** — Hosted MCP sessions (signed `fcmcp_` delegated credential or `x-firecrawl-keyless-secret`) now draw from a dedicated `MCP_CREDITS` Autumn balance before the endpoint's own `CREDITS`, across v2 scrape, search, map, crawl, batch scrape, parse, developer search, agent runs, browser/interact sessions, and Alexandria executions, and get raised per-minute rate limits plus a hobby-tier concurrency floor on v2 so an LLM turn with several parallel tool calls isn't rejected before the credit gate.
- **Dual-auth OIDC for Vercel Marketplace** — Vercel Marketplace integrations can now authenticate with short-lived OIDC JWTs on `Authorization: Bearer <jwt>` alongside the existing `FIRECRAWL_API_KEY`, matching Vercel's migration off of a long-lived injected secret; verification is RS256 with a cached JWKS.
- **TLS certificates verified by default** — `skipTlsVerification` now defaults to `false` on v1 and v2 scrape options. Sites with invalid certificates return `SCRAPE_SSL_ERROR` unless the request opts out; ZDR still forces verification on.
- **`X-Integration` header, credit-usage breakdown, and Keyless World ID buckets** — Clients that cannot modify request bodies can now attribute usage with an `X-Integration` header on every job-creating route; `GET /v2/team/credit-usage/historical` accepts `byEndpoint=true` and `bin=day` for a per-endpoint, per-day split; and keyless users can verify a World ID through `POST /v2/keyless/world-id/device` + `/token` to pin into a per-human daily bucket with 20% more requests and credits than the per-IP tier.
- **Country for browser and interact sessions** — `POST /v2/browser` now accepts `location.country`, and interact sessions created from a scrape inherit `location.country`, so sessions come up from the geography the scrape asked for instead of always running from the US.
- **Auto-resume for large-document scrapes** — The JavaScript and Python SDKs now transparently resume `/scrape` when the API signals `processing_continues`, so oversized PDF scrapes turn into one slow successful call instead of a retry loop.
- **PDF page attribution and image OCR by default** — Added `parsers[].pageMarkers` for inline page markers in `document.markdown`, `parsers[].pages` for per-page markdown, and `parsers[].blocks` for typed PDF layout blocks; raster PNG, JPEG, WebP, AVIF, and JPEG 2000 inputs now route through the image parser and return a one-page OCR document.
- **Prompt-injection guard for JSON extraction** — `checkPromptInjection` is now a top-level scrape option across every endpoint that scrapes (and across every SDK), running a classifier on the page once per scrape and failing fast with `SCRAPE_PROMPT_INJECTION_DETECTED` on detection.
- **Abortable crawls in JS and Python** — `crawl()` now stops polling and cancels its server-side job when the caller aborts (JS `AbortSignal`, Python `asyncio` cancellation), so a timed-out caller no longer leaves a crawl burning credits.
- **Named credit-gate 402s** — `402` responses from the credit gate now carry a `code` naming the limit that refused the request (`insufficient_credits`, `api_key_spend_limit`, `mcp_credits_exhausted`, `platform_managed_credits`) plus `remaining_credits` / `requested_credits`, and Gateway-account users are told to contact the platform that funds their team instead of a plan-upgrade page they can't access.
- **GitHub search retired** — Removed the `github` value of `/v2/search` `categories` with a precise `400`, and retired `GET /v2/search/research/github` (and the legacy `/v2/research/github`) with `410 Gone` pointing callers at the Developer Index.
- **Per-team agent ZDR retention tier, per-org FirePDF training opt-out, and recommendations endpoint** — The `agentZdrRetentionMinutes` team flag cuts the ZDR agent result window to 15, 30, 60, 360, or 1440 minutes with `expiresAt` derived from the configured retention; `trainingRestricted` opts an org out of FirePDF's model-training capture independently of ZDR; and `GET /v2/exchange/recommendations` returns Exchange providers suggested from the caller's own last-30-day Firecrawl usage, so dashboard, MCP apps, and ChatGPT share one Recommended shelf.
