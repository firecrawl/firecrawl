## v2.12.0 is live

Firecrawl v2.12.0 ships `firecrawl-local`, a single Rust binary that scrapes, crawls, and maps the web from the user's own machine; Alexandria provider tools and connectors with natural-language discovery, a new `skills` search source, reciprocal-rank-fused tool matching, Alexandria feedback tokens, and `GET /v2/exchange/recommendations`; X / twitter.com posts and profiles routed through the Exchange at 5 credits instead of 30; enterprise Safe Mode, Threat Protection, IP and API-key scope lockdown, and SIEM Logging; a `usOnly` team flag that pins every model, search, Exchange, agent, PDF/OCR, and page fetch to US capacity; a `reservedCapacity` team flag for reserved PDF-service capacity; HLS session replay and zero-data-retention across `/interact`, `/browser`, and `/agent` with per-team ZDR retention tiers; full agent list/effort/safe/terms/country/traces controls across every SDK; developer search in every first-party SDK; `GET /v2/parse/formats`; a free `gov` search category with filters, a 300/min cap, and optional Government Index routing for plain web searches that are about government topics; country selection for browser and interact sessions; the new `menu` scrape format; image OCR by default; dual-auth OIDC for Vercel Marketplace (now on by default); hosted MCP sessions that admit a shortened browser when credits are short; TLS certificates verified by default; `/health/liveness` and `/health/readiness` at unversioned paths — plus a Dec 10 2026 sunset on all remaining v0, v1, extract, deep-research, and llmstxt routes with per-team `deprecationExtensions`.

### Highlights

- **Firecrawl Local** — `firecrawl-local`, a Rust binary under `apps/local`, scrapes, crawls, and maps the web from the user's own machine with no database, queue, or container (idles at ~11 MB). `firecrawl-local scrape | crawl | map` return API-shaped JSON, `firecrawl-local serve` answers `/v2/scrape`, `/v2/map`, `/v2/crawl`, and `/v2/batch/scrape` on loopback so existing SDKs work when pointed at it, and `firecrawl-local mcp` runs the `firecrawl-mcp` package against the local API; JavaScript pages use the Chrome already on the machine behind a loopback SOCKS5 proxy with SSRF rules on every connection, and cloud fallback is keyless until sign-in.
- **X posts and profiles through the Exchange** — X / twitter.com posts and profiles now take the same route as LinkedIn profiles: scrape looks the URL up in the Exchange catalog and the `exchange` engine fetches the record for every team. A post or profile scrape now costs 5 credits (down from 30), and self-hosted deployments need `FIRE_EXCHANGE_URL` instead of their own `XAI_API_KEY`.
- **Alexandria provider tools, connectors, feedback tokens, and natural-language discovery** — Discover and execute third-party provider tools through Firecrawl. Search with any natural-language query to get back tool contracts; scrape with `domainTools: true` to attach tools matched to a page's domain; or scrape with an `alexandria` body to execute one to ten provider calls with idempotent replays. Every Alexandria call result now carries a signed 24-hour `feedbackToken`, and `/v2/feedback` with `endpoint: "alexandria"` accepts `tokens` and `callRatings` so one rating can attribute to a session of provider calls even after the 20-minute window. Tool discovery now fuses raw-query and model-rewritten matches with reciprocal rank fusion (default on via `ALEXANDRIA_TOOL_FUSION`), and teams with the `exchangeRetrieve` flag can connect their own remote MCP server as a private Alexandria provider through `/v2/exchange/connectors*`.
- **US-only processing** — New `usOnly` team flag routes every model call (OpenAI through the US-only project key, Anthropic with `inference_geo: "us"`, Vertex through the US multi-region endpoint), search/map/research/gov/Exchange calls, `/v2/agent` runs, PDF parsing / image OCR / PII redaction, and page fetches (chrome-cdp, tlsclient, and Hangar browsers all forced to US exits) to US capacity. Labs Search is refused outright and research/developer upstream US-only refusals are relayed as `US_ONLY_UNAVAILABLE`; features without a US route fail with `403 US_ONLY_UNAVAILABLE` instead of degrading quietly.
- **Safe Mode, Threat Protection, IP Restriction, API key scope lockdown, SIEM Logging, and `reservedCapacity` PDF parsing** — A pack of enterprise controls: org-level Safe Mode across every scrape-adjacent endpoint, URL-level threat classification through Google Web Risk or Zscaler ZIA (billed `+2` credits per scanned URL), per-team API key IP allowlists (IPv4, IPv6, CIDR), per-key allowlists for output formats and endpoint groups enforced server-side, org-scoped SIEM Logging that delivers scrape activity events to third-party destinations, and a new `reservedCapacity` team flag that restricts PDF and image parsing to reserved PDF-service capacity (refused with `403 RESERVED_CAPACITY_UNAVAILABLE` when unavailable).
- **Session Replay and ZDR for `/interact`, `/browser`, and `/agent`** — `GET /v2/interact/:sessionId/replay` and `/replay/:pageId` return HLS playlists of recorded browser tabs with pre-signed segments (opt in with `recordSession: true`). Sessions, `/v2/browser`, and `/v2/agent` all now accept `zeroDataRetention: true`, with recording and saved profiles rejected, child calls inheriting the flag, request content dropped from logs, ZDR sessions restricted to Firecrawl's ZDR proxy exits, and (for `/v2/agent`) Exchange still available on ZDR-safe provider capabilities.
- **Agent list, effort, country, terms, safe search, traces, and full-SDK parity** — `GET /v2/agent` with cursor pagination and per-run threading metadata, `effort: "low" | "medium" | "high"` running against `spark-2`, `location: { country }` for a run-wide proxy country, `exchange.onTermsRequired: "skip" | "ask"`, a new `safe` option that filters explicit content from every search the agent makes (sub-agents included), `partial` / `partialSchemaValid` / `stopReason` on failed runs, plus `GET /v2/agent/:id/trace` and `/snapshots/:snapshotId`. The JavaScript, Python, Go, Rust, Java, .NET, PHP, Ruby, and Elixir SDKs all accept `exchange`, `threadId`, `mode`, and `location.country` on `POST /v2/agent`, and the .NET SDK now ships the full agent and Interact surface.
- **Deprecation sunsets with per-team extensions** — Every v0 and v1 route and `/v1/extract`, `/v1/deep-research`, and `/v1/llmstxt` now carry `Sunset: Thu, 10 Dec 2026 15:00:00 GMT` and a migration-guide `Link: rel="deprecation"`. From the sunset on, these routes answer `410 ENDPOINT_REMOVED` unless the team's new `deprecationExtensions` flag names the surface (`v0`, `v1`, `extract`, `deep_research`, `llmstxt`) with a later end date.
- **`gov` search category with filters, Government Index routing, and a new `skills` source** — Added a free `gov` category on `POST /v2/search` and a dedicated `POST /v2/search/gov` endpoint with optional `jurisdiction`, `court`, `courtType`, `cites`, and `domain` filters, now capped at 300 requests/minute. `GOV_ROUTING_ENABLED` optionally routes plain web searches whose queries classify as government through the Government Index. `POST /v2/search` also picks up a new `skills` source that returns provider-authored skill cards alongside web and Alexandria results, free and not counted in `creditsUsed`. Gov and research indexes share a per-plan daily budget (1,000/day on Free–Standard and keyless, 2,000 on Growth, unlimited on Scale and Enterprise), and each index's per-minute limit is now shared across every entry point with `429 code: "index_rate_limit"` over the cap.
- **`GET /v2/parse/formats` and the `menu` scrape format** — New read-only endpoint lists every upload type `/v2/parse` accepts (format id, kind, extensions, MIME types, and per-deployment availability) across all nine SDKs, and a new deterministic `menu` scrape format returns restaurant menu data in `document.menu` behind the `menuBeta` team flag.
- **Developer search in every SDK** — Added `developerSearch` / `developer_search` methods (and the Elixir equivalent) on `POST /v2/search/developer` to the Go, Rust, Java, PHP, Ruby, .NET, and Elixir SDKs, bringing every first-party SDK to parity with the existing JavaScript and Python surface.
- **MCP credits and shortened sessions for hosted MCP** — Hosted MCP sessions (signed `fcmcp_` delegated credential or `x-firecrawl-keyless-secret`) now draw from a dedicated `MCP_CREDITS` Autumn balance before the endpoint's own `CREDITS`, across v2 scrape, search, map, crawl, batch scrape, parse, developer search, agent runs, browser/interact sessions, and Alexandria executions, and get raised per-minute rate limits plus a hobby-tier concurrency floor. A hosted MCP browser-create or prompted interact that cannot reserve its full 600-second charge is now admitted for the largest charge, from a one-minute minimum up, that the balance covers, with `max_lifetime_seconds` set on the browser service so settlement cannot exceed the admitting credits.
- **Dual-auth OIDC for Vercel Marketplace (on by default)** — Vercel Marketplace integrations can now authenticate with short-lived OIDC JWTs on `Authorization: Bearer <jwt>` alongside the existing `FIRECRAWL_API_KEY`; `VERCEL_MARKETPLACE_INTEGRATION_ID` defaults to Firecrawl's integration id so the branch is on wherever DB auth is on.
- **TLS certificates verified by default** — `skipTlsVerification` now defaults to `false` on v1 and v2 scrape options. Sites with invalid certificates return `SCRAPE_SSL_ERROR` unless the request opts out; ZDR still forces verification on.
- **`X-Integration` header, credit-usage breakdown, and Keyless World ID buckets** — Clients that cannot modify request bodies can now attribute usage with an `X-Integration` header on every job-creating route; `GET /v2/team/credit-usage/historical` accepts `byEndpoint=true` and `bin=day` for a per-endpoint, per-day split; and keyless users can verify a World ID through `POST /v2/keyless/world-id/device` + `/token` to pin into a per-human daily bucket with 20% more requests and credits than the per-IP tier.
- **Country for browser and interact sessions** — `POST /v2/browser` now accepts `location.country`, and interact sessions created from a scrape inherit `location.country`, so sessions come up from the geography the scrape asked for instead of always running from the US.
- **Auto-resume for large-document scrapes** — The JavaScript and Python SDKs now transparently resume `/scrape` when the API signals `processing_continues`, so oversized PDF scrapes turn into one slow successful call instead of a retry loop.
- **PDF page attribution and image OCR by default** — Added `parsers[].pageMarkers` for inline page markers in `document.markdown`, `parsers[].pages` for per-page markdown, and `parsers[].blocks` for typed PDF layout blocks; raster PNG, JPEG, WebP, AVIF, and JPEG 2000 inputs now route through the image parser and return a one-page OCR document.
- **Prompt-injection guard for JSON extraction** — `checkPromptInjection` is now a top-level scrape option across every endpoint that scrapes (and across every SDK), running a classifier on the page once per scrape and failing fast with `SCRAPE_PROMPT_INJECTION_DETECTED` on detection.
- **Abortable crawls in JS and Python** — `crawl()` now stops polling and cancels its server-side job when the caller aborts (JS `AbortSignal`, Python `asyncio` cancellation), so a timed-out caller no longer leaves a crawl burning credits.
- **Named credit-gate 402s** — `402` responses from the credit gate now carry a `code` naming the limit that refused the request (`insufficient_credits`, `api_key_spend_limit`, `mcp_credits_exhausted`, `platform_managed_credits`) plus `remaining_credits` / `requested_credits`, and Gateway-account users are told to contact the platform that funds their team instead of a plan-upgrade page they can't access.
- **GitHub search retired** — Removed the `github` value of `/v2/search` `categories` with a precise `400`, and retired `GET /v2/search/research/github` (and the legacy `/v2/research/github`) with `410 Gone` pointing callers at the Developer Index.
- **Per-team agent ZDR retention tier, per-org FirePDF training opt-out, `/health/liveness` and `/health/readiness`, and recommendations endpoint** — The `agentZdrRetentionMinutes` team flag cuts the ZDR agent result window to 15, 30, 60, 360, or 1440 minutes with `expiresAt` derived from the configured retention; `trainingRestricted` opts an org out of FirePDF's model-training capture independently of ZDR; liveness and readiness probes now answer at unversioned `/health/*` paths so probes no longer depend on the deprecated v0 router; and `GET /v2/exchange/recommendations` returns Exchange providers suggested from the caller's own last-30-day Firecrawl usage, so dashboard, MCP apps, and ChatGPT share one Recommended shelf.
