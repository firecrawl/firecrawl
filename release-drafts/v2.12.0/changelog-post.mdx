## v2.12.0 is live

Firecrawl v2.12.0 introduces Alexandria provider tools, an enterprise Safe Mode across every endpoint, HLS session replay for `/interact`, agent list and effort controls, the new `menu` scrape format, image OCR by default — plus a long list of security and reliability fixes.

### Highlights

- **Alexandria provider tools** — Discover and execute third-party provider tools through Firecrawl. Search with `sources: ["alexandria"]` to get back tool contracts, scrape with `domainTools: true` to attach tools matched to a page's domain, or scrape with an `alexandria` body to execute one to ten provider calls with idempotent replays. Available in the JavaScript, Python, Go, and Rust SDKs.
- **Safe Mode** — New enterprise Safe Mode enforced across `/scrape`, `/crawl`, `/batch/scrape`, `/search`, `/map`, `/extract`, `/interact`, and `/monitor`. Restricted sites terminate the scrape, blocked options return `403 SAFE_MODE_BLOCKED`, and Lockdown runs cache-only with zero data retention.
- **`menu` scrape format** — Added a deterministic structured `menu` format that returns restaurant menu data in `document.menu`, available in all 9 SDKs and gated behind the `menuBeta` team flag.
- **Session Replay for `/interact`** — Added `GET /v2/interact/:sessionId/replay` and `/replay/:pageId` returning HLS playlists of recorded browser tabs with pre-signed segments, plus a `recordSession` option (default `true`) on session create.
- **Agent list, effort, traces, and snapshots** — Added `GET /v2/agent` with cursor pagination and per-run threading metadata, `effort: "low" | "medium" | "high"` on `POST /v2/agent` running against `spark-2`, plus `GET /v2/agent/:id/trace` and `/snapshots/:snapshotId`. Wired through nine SDKs.
- **Auto-resume for large-document scrapes** — The JavaScript and Python SDKs now transparently resume `/scrape` when the API signals `processing_continues`, so oversized PDF scrapes turn into one slow successful call instead of a retry loop.
- **Threat Protection, IP Restriction, and API key scope lockdown** — Three new enterprise controls: URL-level threat classification through Google Web Risk or Zscaler ZIA (billed `+2` credits per scanned URL), per-team API key IP allowlists (IPv4, IPv6, CIDR), and per-key allowlists for output formats and endpoint groups enforced server-side.
- **SIEM Logging** — Added org-scoped SIEM Logging that delivers scrape activity events to third-party destinations through a shared, replica-safe queue with retries.
- **PDF page attribution** — Added `parsers[].pageMarkers` for inline page markers in `document.markdown`, `parsers[].pages` for per-page markdown, and `parsers[].blocks` for typed PDF layout blocks.
- **Image OCR by default** — Raster PNG, JPEG, WebP, AVIF, and JPEG 2000 inputs now route through the image parser and return a one-page OCR document.
- **Prompt-injection guard for JSON extraction** — Added an opt-in `checkPromptInjection` on JSON-mode extraction that runs a classifier on scraped content and fails fast with `SCRAPE_PROMPT_INJECTION_DETECTED` on detection.
- **Developer / Code Search out of beta** — Removed the `developerBeta` gate so `POST /v2/search` accepts the `developer` category and `POST /v2/developer/search` works for every team.
